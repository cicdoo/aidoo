Aidoo

Chat with your Odoo — safely.

An in-Odoo AI assistant powered by the Claude Code CLI. It answers questions, queries your data, and builds reports — running as the logged-in user, never as superuser, with a full audit trail.

Security first — by design

🔒 Runs as the user

Every ORM action executes with su=False. The user's access rights and record rules are enforced automatically — the model can never see or do more than the person using it.

🧮 Read-only SQL, really

sql_select is double-guarded: a SELECT-only validator plus Postgres SET TRANSACTION READ ONLY and a statement timeout, gated to a dedicated AI SQL Analyst group.

🧾 Full audit log

Every tool call — model, method, SQL, row counts, outcome, even denials — is written to an immutable log on a separate committed cursor, so it survives rollbacks.

🔑 Per-user OAuth

Each user authorizes with their own Claude subscription. No shared API key; credentials are stored per user (mode 0600), never in the database.

No shell. No web. No surprises.

Claude's built-in tools (Bash, file write, web, agent spawners) are hard-denied. The model acts only through a small set of Odoo tools over a loopback bridge that holds no database credentials — just a short-lived, session-scoped capability token. Replies and tool activity stream into the chat in real time over the Odoo bus.

What it can do

  • Answer questions about your records in natural language
  • Search, read, and group data with the user's permissions
  • Run read-only SQL reports (for the SQL Analyst group)
  • Stream answers and tool steps live into the chat
  • Opt-in, per-user write tools (create / write / unlink / actions)
  • Zero-trust mode to strip writes globally or per user
  • Manager audit log of every tool call and denial
  • Per-user OAuth login — no shared subscription

Remote MCP server

It is enabled by default (Settings → Aidoo has a checkbox to disable it). Create an API key with scope aidoo_mcp, and point your MCP client at /aidoo/mcp. Same per-user tool grant and audit log as the chat.

{"mcpServers":{"odoo":{"type":"http","url":"https://HOST/aidoo/mcp","headers":{"Authorization":"Bearer <key>"}}}}
